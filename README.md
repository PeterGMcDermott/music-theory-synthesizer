# Music Theory Synthesizer

A synth with a visualizer for people learning music theory and how to build beats. It has a playable keyboard, a 5-track 16-step sequencer, a live waveform visualizer, and tempo and swing controls.

The coaching track works Duolingo-style: a four-stage quest with XP that walks through keys, scales, and beat building, unlocking as you go. You can export a loop as MP3, save and reopen project files, and there is a step-by-step guide for uploading to SoundCloud.

Open `index.html` in a browser and it works. MP3 export loads its encoder from a CDN, so that one needs internet. Note: progress auto-saves in the browser when self-hosted; the hosted preview blocks browser storage, so use the project file download there.
